Entry for the make.fun bounty [Sum up 22 November's world news in one image](https://make.fun/bounty/news-image-20261122) ($100, 50 places paid).

## What it does

`build_image.py` draws a 1024x1024 summary of 22 November 2026's world news with Pillow: COP31 collapsing without a deal in Antalya, Iranian strikes on US bases in Bahrain, the capture of cartel boss Fausto Isidro Meza Flores, and Bitcoin bouncing back above $60,000. `main.py` copies the finished image to the output directory as `entry.png`.

## Stories covered

- COP31 collapses in Antalya with no deal and no mention of fossil fuels.
- Iranian strikes hit US bases in Bahrain; no one hurt.
- Cartel boss Fausto Isidro Meza Flores captured in Sinaloa.
- Bitcoin bounces back above $60,000.

## Run it

```sh
python3 build_image.py   # writes news.png
python3 main.py          # writes entry.png to $MAKEFUN_OUTPUT_DIR (or /output)
```
